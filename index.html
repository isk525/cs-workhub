アクセスログ抽出SQL

SQLをコピーし、Popupで開いたpgAdminへ貼り付けて使用します。

SELECT
    SUBSTR(access_datetime, 1, 10) AS access_date,
    user_id,
    "ユーザ自治体名",
    NULL AS business_id  -- business_idをNULLで出力
FROM
    (
        SELECT
            a.account_id,
            (SELECT REPLACE(c.prefecture || c.municipality, ',', '、') FROM account b, municipality c WHERE b.id = a.account_id AND c.id = b.municipality_id) AS "ユーザ自治体名",
            (SELECT REPLACE(b.user_id, ',', '、') FROM account b WHERE b.id = a.account_id) AS "user_id",
            TO_CHAR(a.access_datetime, 'YYYY/MM/DD HH24:MI:SS') AS access_datetime
        FROM
            access_log a
        WHERE
            a.access_datetime > '2026-06-01'
            AND (SELECT REPLACE(c.prefecture || c.municipality, ',', '、') FROM account b, municipality c WHERE b.id = a.account_id AND c.id = b.municipality_id) IS NOT NULL
            AND (SELECT REPLACE(c.prefecture || c.municipality, ',', '、') FROM account b, municipality c WHERE b.id = a.account_id AND c.id = b.municipality_id) <> ''
    ) AS subquery
GROUP BY
    access_date,
    user_id,
    "ユーザ自治体名" -- access_date, user_id, ユーザ自治体名でグループ化
ORDER BY
    access_date,
    user_id;

SQLの開始日は「2026-06-01」です。必要に応じてコピー後に変更してください。

直近ログイン状況SQL

自治体アカウントの最終ログイン日を確認するSQLです。

SELECT
  a.municipality_id,
  a.user_id,
  TO_CHAR(a.last_login_datetime, 'YYYYMMDD') AS last_login_date,
  m.prefecture || m.municipality
FROM
  account AS a
INNER JOIN
  municipality AS m
ON
  a.municipality_id = m.id
where a.deleted = false and m.municipality <> '' and m.disclosed = true and TO_CHAR(a.last_login_datetime, 'YYYYMMDD') >= '20260101';

抽出開始日は「20260101」です。必要に応じてコピー後に変更してください。
